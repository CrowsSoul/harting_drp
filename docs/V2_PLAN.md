# 第二版规划与分组（V2）

> V1 已交付 44 项检查与报告；V2 分三个小组推进，组内测试通过后统一发布。

## 一、界面架构小组（赵文哲）

**成员**：赵文哲（组长）、陈卉妍、杜滨芳

负责整个平台的可视化，做成工业软件的操作风格；负责与 NX 的衔接，能在平台上直接调起 NX 界面、自动设置参数并执行仿真；同时负责大模型 API 接入（先接 DeepSeek），做到用语义指令下达任务，由 AI 自动完成仿真与评测。

## 二、电气安规检查小组（宋馨雨）

**成员**：宋馨雨（组长）、汪琪竣

借助 AutoCrear 的工具，用 AI 把其中的电气检查规则（SAF）提取出来。目前没有公开免费版，先用 DeepSeek 做规则分析与复现，必要时再用 apt astra 一类工具做逆向分析（动手前先过合规确认）。

## 三、DFM 组件检查小组（张百瑞）

**成员**：张百瑞（组长）、代世航、于大淇

借助 NX 的 Check-Mate 插件，用 AI 梳理它的检查规则，让我们自己的检查组件复刻其中的计算规则和算法：把现在“填参数、比阈值”的判定，改成 Check-Mate 里的公式和比较规则。

## 四、发布（于大淇）

每个小组组内测试通过后，把最终版本推送到 GitHub 仓库。GitHub 推送目前有问题，由于大淇统一负责（分支、权限与 CI 门禁）。
